:: ================================================================
::  GarrisonFarm PC —— 明日方舟「卫戍协议·极速模拟」自动刷策略角标
::  官方 PC 启动器 / MAA 生态适配版
:: ================================================================
::
:: 【它能做什么】
::   自动反复打「极速模拟」刷策略角标：自动选策略、买干员、升级商店、摆放干员、
::   打完结算，再开下一局。启动后先选择模式：
::     1. 标准模式 · 金色角标：同一策略通关 3 次           需要配置自选编队
::     2. 标准模式 · 彩色角标：同一策略通关 6 次（镀层）   需要配置自选编队
::     3. 低配模式 · 金色角标                               不需要自选编队
::     4. 低配模式 · 彩色角标                               不需要自选编队
::   程序会把同一个策略连续打满 3 次（或 6 次）再换下一个；已有对应角标的策略自动跳过。
::
:: 【第一次使用前（只需一次）】
::   1. 电脑上装好 MAA（本程序只读取 MAA 的配置和 PaddleOCR 模型，不修改 MAA）。
::   2. **以管理员身份运行本程序**（右键 →“以管理员身份运行”，或直接双击后同意 UAC 提权）。
::      官方 PC 端的游戏进程由反作弊以管理员权限运行，低权限进程截图会全黑、点击无效。
::   3. 打开鹰角启动器进入游戏；游戏设置里保持 16:9、**窗口化 1920x1080** 最稳，
::      游戏内 UI 缩放 100%，鼠标指针比例调小。
::   4. 游戏使用默认界面：主界面、卫戍协议界面都不要使用 UI 皮肤或主题。
::   4. 标准模式：在「卫戍协议 - 自选编队」里配置程序提示的推荐干员。
::      低配模式：自选编队留空即可，只用游戏预设干员。
::   5. 建议先运行 GarrisonFarmPC.exe --check 做一次自检（会保存一张截图）。
::
:: 【每次使用】
::   1. 打开鹰角启动器和游戏，进入「卫戍协议」主界面（能看到「极速模拟」按钮）。
::      有没打完的对局（显示「断线重连」）也可以直接开始。
::   2. 运行本文件，输入 1~4 选择模式并回车，弹出「使用前提醒」后点「确定」。
::   3. 运行期间不要用鼠标操作游戏窗口（程序要移动真实光标来点击）；
::      窗口可以放后台或被遮挡，但不要最小化。
::   停止：关闭本窗口，或按 Ctrl+C。
::
:: 【程序会自己停下的情况（保护机制，不是出错）】
::   - 启动时不在卫戍协议界面：弹窗提示后退出。
::   - 运行中 30 秒看不到卫戍协议界面（掉线、重新登录等）：立即停止。
::   - 10 分钟没有任何进展：判定卡死并停止，截图保存在 farm_logs。
::
:: 【打法简介】
::   第 1 回合买 2 个干员（最多 1 个医疗），之后优先升级商店，第 4~5 回合满级；
::   满级后只买 5、6 级干员，没有就刷新，按所选模式的干员权重优先购买；不买装备。
::   干员全部朝右，只放在地图最右侧 3 列（不含红门列）的 8 个格子：
::   2 个木框高台（安全位）优先给远程输出，其余干员优先放在最上面两行的敌人路径上。
::
:: 【配置】
::   settings.json（可参考 settings.example.json）：设备、MAA 目录、截图/输入方式、
::   鼠标停靠点、日志目录等。删掉该文件即恢复默认。
::
:: 【常见情况】
::   - 进对局后会显示鹰角 logo 约 1 分钟：这是 PC 端加载，属于正常，程序会自动等待。
::   - 日志里出现「无法购买」：多半是备战席已满（买了但还没上场的干员占了位置），
::     等程序部署完或手动点一次「准备就绪」推进一回合即可。
::   - 截图全黑：先确认是管理员身份运行；仍不行把 settings.json 里的
::     win32.screencap 改成 gdi 或 screendc 再试。
::   - 想看得更细：加 --debug 参数运行，日志会打印购买/部署的判定过程。
::
:: 【出问题时】
::   把 farm_logs 文件夹里的 run.log 和最近的截图发出来；
::   找不到窗口时先运行 GarrisonFarmPC.exe --list-windows 看看窗口标题。
:: ================================================================
